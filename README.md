# 📡 Optimisation du Placement des Antennes Mobiles

Ce projet vise à optimiser la couverture du réseau mobile dans les zones mal desservies à l’aide de techniques d’optimisation mathématique.

##  Contexte

Dans un monde de plus en plus connecté, une bonne couverture réseau est essentielle. Pourtant, de nombreuses zones restent mal couvertes dans nos pays. Pour remédier à cela, nous avons cherché à **optimiser le placement des antennes mobiles** afin de :

- Maximiser la couverture réseau
- Réduire les interférences
- Minimiser les coûts

Ce projet a été réalisé sous la supervision du **Dr Oumar Diop**, docteur en mathématiques, par **Soma Ben Idriss Diloma** et **Yves [NomComplet]**.

##  Méthodologie

Nous avons utilisé des **métaheuristiques** puissantes pour résoudre ce problème d’optimisation sans équation explicite :

- **MADS** (Mesh Adaptive Direct Search)
- **Recherche Tabou**

Ces deux méthodes combinées nous ont permis de proposer un placement optimal des antennes, tout en prenant en compte certaines contraintes terrain (zones de non-couverture, budget limité, etc.).

## Technologies et outils

- Python (NumPy, Matplotlib, etc.)
- Algorithmes d’optimisation
- Données géographiques simulées

## Résultats

- Simulation de couverture améliorée par rapport à un placement aléatoire
- Réduction significative des interférences
- Visualisations des zones couvertes avec les emplacements optimaux
